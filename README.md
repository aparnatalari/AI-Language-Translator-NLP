# 🌍 AI Language Translator using NLP & Streamlit

An AI-powered Language Translation Web Application that translates English text into Hindi in real-time using Natural Language Processing (NLP) techniques and Text-to-Speech technology.

The application provides an interactive web interface, translation history tracking, and Hindi voice output for enhanced accessibility and user experience.

# ⚙️ Features

## 🌐 Real-Time Translation

Instant English-to-Hindi text translation.

## 🔊 Voice Output

Translated Hindi text is automatically converted into speech using Text-to-Speech technology.

## 📜 Translation History

All translated text is stored locally for future reference.

## 💻 Interactive Web Application

Built using Streamlit for a responsive and clean UI experience.
